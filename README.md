# sarah-veil

Small, self-contained web things. **No accounts, no tracking, no servers** — everything runs in the
browser, and every one of them works with the wifi off.

---

## What's here

### [The Daily Decan](https://sarah-veil.github.io/daily-decan/) · 每日旬星

Two cards, both derived from the sky, neither drawn at random.

- **Today's card** — the decan the Moon is standing in right now. The same card for everyone alive.
- **Your birth decan** — the decan the Moon stood in on the day you were born. Yours alone.

Every step of both derivations is printed on the page, so you can check it against any ephemeris.

`tarot` `astrology` `single-file` `pwa` `offline-first` · [source](https://github.com/sarah-veil/daily-decan) · [v1.0.0](https://github.com/sarah-veil/daily-decan/releases/tag/v1.0.0)

### [What Did You Dream?](https://sarah-veil.github.io/what-did-you-dream/)

Type a dream. It finds the symbol words in it — and shows you **which words it matched**, so you can
judge the reading for yourself instead of taking its word for it. 84 symbols, hand-written.

`dreams` `single-file` `offline-first` · [source](https://github.com/sarah-veil/what-did-you-dream) · [v1.0.0](https://github.com/sarah-veil/what-did-you-dream/releases/tag/v1.0.0)

## The rule I keep

Every project here makes **zero network requests**. No analytics, no cookies, no fonts from a CDN.

You can open any of them from a local file with the network off and they behave identically. Where
something optional would need a request — a page counter, a feedback form — it ships **switched off**,
and the wording on the page changes to match when you switch it on. The claim stays true either way.
